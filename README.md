# Mock-тестирование в Python

Учебный проект: презентация и примеры кода по mock-тестированию в Python.

## О чём этот проект?

Mock-тестирование — это подход к тестированию, при котором внешние зависимости (базы данных, API, файловая система) заменяются на «дублёры» — моки. Это позволяет изолировать тестируемый код, ускорить тесты и сделать их предсказуемыми.

Репозиторий содержит:

- Презентацию по mock-тестированию (для Obsidian)
- Примеры кода с моками (`unittest.mock`)
- Рабочие тесты с использованием `MagicMock` и `patch`

## Презентация

Презентация находится в файле `presentation/mock-presentation.md` и написана в формате Obsidian Slides.

Как запустить:

1. Открыть файл в Obsidian.
2. Включить плагин Slides (Настройки → Основные плагины → Slides(Слайды)).
3. Открыть командную палитру (Ctrl+P) и выбрать «Slides: Start presentation».

О чём рассказывается в презентации:

- Проблема: тесты зависят от внешнего мира
- Решение: Mock-объекты
- Недостатки моков
- Подключение в Python (`unittest.mock`)
- Три способа создания мока
- Основные методы (`return_value`, `side_effect`, `assert_*`)

## Что такое Mock?

Mock (мок) — это объект, который имитирует поведение реального объекта в контролируемых условиях.

Мок заменяет реальную зависимость и позволяет:

- Изолировать тестируемый код от внешнего мира
- Контролировать поведение зависимости
- Проверять взаимодействие с зависимостью
- Ускорять тесты в десятки раз
- Делать тесты предсказуемыми

Золотое правило: мокай то, что тебе не принадлежит. Свой код тестируй по-настоящему.
